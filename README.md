# ⛳ El Putt Perfecto

**Un hoyo. Un golpe. ¿Entra o no?**

[▶️ JUGAR](https://goyoaga.github.io/el-putt-perfecto/)

El Putt Perfecto es un microjuego de **UNAMAS GAMES** pensado para partidas de pocos segundos. Mira el hoyo, ten en cuenta el viento y decide dirección y potencia con un único gesto.

## Cómo se juega

1. Toca la bola.
2. Arrastra hacia atrás para apuntar y cargar potencia.
3. Suelta.
4. Después solo puedes mirar.

Cada ronda cambia ligeramente la posición del hoyo, la distancia y el viento. Solo tienes **un golpe**.

**PUTT PERFECTO** si entra. Si no, intenta dejarla lo más cerca posible.
