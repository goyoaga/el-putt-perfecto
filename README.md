## El reto

Lee el **viento** y la **caída del green**, apunta y decide la potencia. Solo tienes un golpe.

**ARRASTRA HACIA ATRÁS** → **SUELTA** → **MIRA LA BOLA** → **UNA MÁS**

Cada ronda cambia la posición de salida, el hoyo, el viento y la pendiente. Si la bola pasa por el hoyo, **entra**.

## Cómo se juega

1. Toca la bola.
2. Arrastra hacia la izquierda, en dirección contraria al golpe.
3. Ajusta dirección y potencia.
4. Suelta.
5. Después solo puedes mirar.

Tu mejor resultado se guarda en este navegador. El sonido empieza **OFF** y puedes guardar el juego en favoritos desde el botón ☆.
